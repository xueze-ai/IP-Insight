# 网鉴 IP Insight v0.2.3 · 网络出口诊断独立成页

> Exit Diagnostics gets its own page — clear tables, real geo per measured exit IP, and honest status semantics.

## ✨ 新增 / What's New

### 🚦 网络出口诊断：独立页面 + 全表格化

左侧新增一级导航「网络出口诊断」。顶部一键「开始全部检测 / 停止」、进度与本轮耗时；概览一句话统计（按唯一 IP 去重，DNS 单独统计）：

> 测得 3 个 HTTP 出口；8 个网站取得出口 IP；2 个仅确认可达；1 个失败；4 个 DNS 递归出口（单独统计）。

四个标签可独立运行、切换保留结果（默认打开**网站分流测试**）：

| 模块 | 呈现 |
| --- | --- |
| **网站分流测试** | 每站一行：网站/域名 · 类别 · 实际出口 IP · 国家/地区·运营商（按测得出口 IP 查询，附来源与时间）· 状态 · 操作；搜索 / 类别筛选 / 仅看失败 / 按出口分组 / 复制 IP / 复制整表 / 单项重试 |
| **本机公网 IP** | 观测点 · 出口 IP · 地址族（IPv4/IPv6 独立成行）· 国家与网络归属 · 请求机制 · 状态；区分「跟随系统代理的 HTTP」与「Node 直连 IPv6」 |
| **CDN 命中节点** | 原始节点标识完整保留（`HKG61-P1` 不裁剪、不推断城市）；缓存信号按响应顺序保留全部段落（`Miss → Hit` 不合并） |
| **DNS 出口查询** | 「系统配置解析器」与「指定公共 DNS」分组；Akamai `ns`/`ip`/`ecs` 官方字段语义；udp4/udp6 按服务器地址；仅 ECS 不算取得出口 |

不回显出口的目标明确显示「**可访问，未提供出口 IP**」——绝不用主出口或别的站结果补齐。

### 🌍 真实归属链路

按测得的唯一出口 IP 查询公共归属 API（ip-api.com，回退 ipwho.is；去重 / 并发 2 / 10 分钟缓存）；哔哩哔哩、IPIP.net 等目标自身提供的归属单独标注来源；归属查询失败保留 IP、显示「未获取」，不算失败。

### 🧰 数据与状态修复

- 综合检测与诊断轮次显式关联（runId），不再依赖全局 latest 猜测；
- 载入历史后出口面板显示**不可变历史快照**，后台实时结果不覆盖；
- AI 流式片段绑定请求 ID：切换检测 / 载入历史后旧请求不污染新视图；
- 停止 / 超时立即终结全部未完成项（可立即重跑），隐藏窗口同步清理；
- 启动即渲染全部目标行（骨架），逐行实时更新，顺序固定不跳动；
- 单项重试保留其他结果与尝试历史（首次时间 + 每次重试时间）；
- 独立诊断可保存为历史、导出、单独交给 AI（不必先跑多源检测）；
- 网络质量页顺序调整为 测速 → 全球节点 → 本机可达性 → 服务可用性，并解释「收到响应 ≠ 账号/地区/权限/整个服务可用」。
